## Column meanings

- **rows examined** — row count of the artifact the other columns are computed from (named in Provenance). NOT a raw search total: bbc_e2e writes its candidates file AFTER the classify loop, so its size depends on that run's env settings. For the one raw funnel, see the xstream block above.
- **production** — rows whose adaptation touches `src/main`.
- **traversal-confirmed** — the client crossed the break boundary in its own history. This is the gate that removes nearly everything.
- **behavioural / compile break** — `screen_compile_break.py` verdicts. Only meaningful for constructor-mediated breaks; POI and h2 return all-unknown because their breaks are a static config call and SQL semantics respectively.
- **VERIFIED** — a 3-state differential was actually run and passed.
