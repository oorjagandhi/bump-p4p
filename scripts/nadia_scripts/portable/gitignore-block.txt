# Rules the BBC toolkit needs in its HOST repository's .gitignore.
#
# `install.py` copies everything below the marker line into <repo>/.gitignore, wrapped in
# a delimited block it can find and replace on the next run. Edit this file, re-run
# install.py, and the host repo picks the change up.
#
# Every rule is written with `**/` rather than a `scripts/nadia_scripts/...` prefix, so it
# keeps matching wherever the toolkit folder is dropped -- repo root, `tools/`, three
# levels down. A prefixed rule that stops matching is invisible: nothing errors, the
# checkpoints and cloned client repos just start getting committed.
# ---8<--- rules below this line are installed ---8<---
